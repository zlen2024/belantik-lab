# Halaman 18: Appendix C, peta stokastik Gaussian

## C.1 Peta Gaussian

Transformasi pmode `T: P(R^N) → P(R^N)` ialah **Gaussian** jika ia memetakan setiap Gaussian kepada Gaussian. Setara: ia **afin dalam momen**:

`μ ↦ Mμ + d`, `Σ ↦ MΣM^T + Δ` (C1), dengan `Δ ≥ 0` simetri.

Satu peta = tiga serangkai `(M, d, Δ)`. **Hukum komposisi (C2):**

`(M2, d2, Δ2) ∘ (M1, d1, Δ1) = (M2 M1, M2 d1 + d2, M2 Δ1 M2^T + Δ2)`.

Membentuk **semigroup** `S_N`: bersekutu, identiti `(I, 0, 0)`. Songsangan dua-hala hanya wujud bila `Δ = 0` dan M boleh songsang: **sebarang suntikan hingar bukan sifar tak boleh balik** pada aras kernel Markov. Ruang konfigurasi sahaja (tiada ruang fasa), maka tiada bentuk simplektik; tiga ramuan bebas `A` (peta linear), `b` (hanyut), `D` (suntikan hingar) menggantikan satu penjana Hamiltonian kuantum.

Propagator terhingga bagi SDE linear `dX = (AX + b) dt + B dW` (C3): `M(t) = e^{At}`, `d(t) = ∫0^t e^{A(t−s)} b ds`, `Δ(t) = ∫0^t e^{As} D e^{A^T s} ds` dengan `D = BB^T`. Momen memenuhi `μ̇ = Aμ + b` dan persamaan Lyapunov pembezaan `Σ̇ = AΣ + ΣA^T + D`. Kira-kira Gaussian pmode **menjadi algebra linear terhingga dimensi**.

**Pemfaktoran SVD (C4):** `(M, d, Δ)` dengan M boleh songsang = `(I,d2,Δ2) ∘ (U2,0,0) ∘ (Σ_S,0,Δ_S) ∘ (V^T,0,0) ∘ (I,d1,0)`. Setiap faktor ortogonal diurai kepada putaran dua-mod satah. Tidak seperti penguraian Bloch-Messiah, tiada struktur simplektik.

## C.2 Pustaka gate Gaussian

| Gate | Tindakan | Tiga serangkai |
|---|---|---|
| `PDisp(α)` | anjak min | `(1, α, 0)` |
| `PScale(r)` | skala min dan varians: `N(e^r μ, e^{2r} σ²)` | `(e^r, 0, 0)`, boleh balik |
| `PMix_ij(θ)` | putaran satah pada dua mod | `(R(θ), 0, 0)` |
| `P2Sq_ij(r)` | putaran hiperbolik, `Cov = sinh(2r)` untuk input `N(0,1)` bebas | |

Bersama penguraian interferometer, gate ini merealisasi setiap unsur `S_N` dengan `Δ = 0` pada kedalaman `O(N)`.
