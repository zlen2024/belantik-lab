# Halaman 4: rantai Markov dan DFG

## II.C Rantai Markov

- Kernel tetap diulang: `ρ_n = K^n ρ_0` (Eq. 8). Taburan pegun `π` memenuhi `Kπ = π`. Bawah ergodisiti (tak terturun dan tak berkala), `ρ_n → π`.
- **Konvensyen:** paper tolak darab dari kiri (`Kρ`, lajur-stokastik), bukan `ρP` (baris-stokastik) seperti kebanyakan buku.
- Dengan langkah kecil `K_τ = I + τQ` (Eq. 9): `Q` ialah **rate matrix**, `Q_ij ≥ 0` untuk i≠j (kadar dari j ke i), `Q_ii = −Σ_{j≠i} Q_ij` (lajur jumlah sifar).
- Had `N → ∞`: `ρ(t) = e^{Qt} ρ_0` (Eq. 10), penyelesaian persamaan Kolmogorov hadapan `dρ/dt = Qρ`. Pegun: `Qπ = 0`.
- Kernel Euler `I + τQ` dan eksponen tepat `e^{Qt}` kedua-duanya muncul sebagai gate.

## II.D Directed Factor Graph (DFG)

- DAG kernel stokastik; output satu kernel jadi input kernel lain. Nod pembolehubah (bulatan) disambung melalui nod factor (segi empat) = kernel `K_i(θ_i)` (Rajah 3).
- Kernel `K_i` ialah **ibu bapa** `K_j` jika outputnya input `K_j`. Susunan topologi: ibu bapa sebelum anak.
- Maka `K(θ) = K_n(θ_n) ∘ ... ∘ K_1(θ_1)` (Eq. 11) dan `ρ_out = K_n ... K_1 ρ_in` (Eq. 12).
- Trajektori sampel: `z(0) ~ ρ_in`, `z(j) ~ K_j(·|z(j−1))`.
- **Tidak** diandaikan bentuk tertutup bagi taburan bersyarat; hanya andaian setiap `K_j` boleh disampel dengan cekap. Parameterisasi licin supaya `∇_θ K(y|x)` boleh dikira.

Hubungan dengan kod: `torx.DFG`, `Site`, `AbstractFactor` (nota wiki 08). Gate Torx ialah factor.
