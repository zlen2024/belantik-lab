# Halaman 6: gate asas

## pbit dan pdit

- `PNOT(p) = [[1−p, p],[p, 1−p]]` (Eq. 18). p=0 identiti, p=1 NOT, p=1/2 seragam tanpa mengira input. `PNOT(p)(α,β)^T = ((1−p)α + pβ, pα + (1−p)β)^T` (Eq. 19).
- `PSWAP(p)|ab) = (1−p)|ab) + p|ba)` (Eq. 20).
- **PIsing** (gate terbit-penjana): `θ = (J, h1, h2, β, Δt)`. Tenaga `E(s) = −J(2s1−1)(2s2−1) − h1(2s1−1) − h2(2s2−1)` (Eq. 21). Kadar Glauber `Q_ab = σ(−β(E(s_a) − E(s_b)))` untuk lompat satu spin (Eq. 22), `PIsing(θ) = exp(Δt Q)` (Eq. 23). Rakan paper [20] menumpukan pada kernel berasaskan tenaga.

## pmode

- **Affine Gaussian** `(M, d, Δ)`: `X ↦ MX + d + ε`, `ε ~ N(0, Δ)`. Memetakan `N(μ,Σ)` kepada `N(Mμ + d, MΣM^T + Δ)` (Eq. 24). Kes khas (anjakan, skala, putaran) dalam Appendix C.
- Gate terbit-penjana: **Ornstein-Uhlenbeck** `POU(γ, D, t)` daripada SDE `dX = −γ X dt + √(2D) dW`; peranan untuk pmode seperti PIsing untuk pbit.
- Primitif Gaussian menyokong algoritma pembolehubah selanjar, termasuk rangkaian neural dalam pada perkakasan superkonduktor ([10]); boleh dilaksanakan dalam CMOS (X0) atau Z1 melalui `thermalizers`.

## Gate hibrid pdit/pmode

- `CShift(α)`: `|k) ⊗ p(x) ↦ |k) ⊗ p(x − α_k)` (Eq. 25).
- `CScale(r)`: `|k) ⊗ p(x) ↦ |k) ⊗ e^{−r_k} p(e^{−r_k} x)` (Eq. 26).
- **Mixture-of-Gaussians** `MoG(π, α)`: sedia ancilla pdit dengan taburan π, kenakan `CShift(α)`, buang ancilla: `p(x') = Σ_k π_k N(x'; μ + α_k, σ²)` (Eq. 27). Penganggar ketumpatan universal. Ini tepat binaan Rajah 2(e)-(f).
