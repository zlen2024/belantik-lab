# Halaman 3: kernel stokastik

**Register n pbit:** ruang `{0,1}^n`, keadaan `ρ ∈ Δ^{2^n − 1}`. Notasi Dirac `|a1...an)` ialah taburan yang meletakkan kebarangkalian 1 pada rentetan tertentu (Eq. 1). Hanya untuk kejelasan.

**Kernel stokastik** `K(y|x)`: positif dan ternormal untuk setiap x (Eq. 2). Diskret = **lajur-stokastik** (setiap lajur jumlah 1). Kesan ke atas taburan: `ρ_out(y) = Σ_x K(y|x) ρ_in(x)` (Eq. 3).

**Jangkaan (Eq. 4-5):** `<f, ρ> = f^T ρ` (diskret) atau `∫ f ρ` (pmode), dan jumlah-kamiran untuk keadaan hibrid. `<f, Kρ> = <K^T f, ρ>`: kernel bertindak **ke hadapan pada keadaan** dan **ke belakang pada observable**. Dualiti ini yang membolehkan objektif litar dibezakan satu gate pada satu masa.

**Komposisi (Rajah 2):**
- Selari (Eq. 6): `(K⊗L)(y,y'|x,x') = K(y|x) L(y'|x')`.
- Siri (Eq. 7): `(L∘K)(y|x) = ∫ L(y|z) K(z|x) dz`; diskret = darab matriks.
- Kernel pada ruang sama membentuk **semigroup** dengan identiti.
- Dua operasi tukar bilangan wire: sedia ancilla pada keadaan tetap `|0)` dan buang (marginalkan) wire.

Empat operasi (`∘`, `⊗`, ancilla, buang) cukup untuk membina setiap kernel dalam paper.

Dalam kod kita, `sample`/`density` mengikut persamaan ini: `StateVectorSimulator.density` ialah `Kρ`, dan lajur setiap gate jumlah 1 (disahkan dengan PCNOT dan POR).
