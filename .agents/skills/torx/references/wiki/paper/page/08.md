# Halaman 8: REINFORCE, parameter-shift, kernel tenaga

## REINFORCE (Eq. 34)

Ambil S trajektori bebas dan purata kurungan: penganggar **tak bias** bagi seluruh gradient daripada satu kelompok larian litar. Memerlukan `G_j > 0` pada sokongan trajektori, benar untuk gate pustaka selagi parameter jauh daripada sempadan `p ∈ {0,1}`; parameterisasi sigmoid memastikan ini secara automatik.

## Parameter-shift (Eq. 35-40)

Untuk `G(θ) = (1−σ(θ)) I + σ(θ) B`: `∂G/∂θ = σ'(θ)(B − I)`, dengan `σ' = σ(1−σ)`.
Takrif `θ⁻` dengan `σ(θ⁻) = σ(θ)²`, iaitu `θ⁻ = −ln((1+e^{−θ})² − 1)` (Eq. 36). **Identiti log-shift (Eq. 37):**

`∂G(θ)/∂θ = G(θ) − G(θ⁻)`

Maka (Eq. 38) `∂<f,ρ_out>/∂θ_j = E_{X~ρ(θ*)}[f(X)] − E_{X~ρ(θ*⁻)}[f(X)]`. Penganggar tak bias (Eq. 40) `ĝ_j = (1/S) Σ f(X_i) − (1/S) Σ f(X̃_i)`, varians `(Var_{p⁺} f + Var_{p⁻} f)/S`.

Dua had: (1) hanya untuk gate bentuk Eq. 17; (2) satu litar teranjak untuk **setiap parameter**, tidak seperti REINFORCE yang guna satu kelompok. Hanya gate hiliran `G_j` perlu disampel semula; sebahagian trajektori boleh digunakan semula.

Nota untuk kod kita: `diff_method="param_shift_inf"` dalam repo guna `θ → ±∞` (deterministik), varian lain daripada identiti ini; kertas menerangkan identiti log-shift. Disahkan daripada `sampled.py`: `param_shift_single` menggunakan shift `θ* = −ln((1+e^{−θ})² − 1)` (Eq. 39), K=2 sahaja dan `reps=1`; `param_shift_inf` menggunakan had `θ → ±∞`; `param_shift_filter` ialah penganggar nisbah. Lihat `../../../gradients.md`.

## Kernel berasaskan tenaga (Eq. 41-44)

`G(θ)(y|x) = e^{−E(x,y;θ)} / Z(x;θ)` (Eq. 41-42). Gradient log-bersyarat (Eq. 43): `−∇_θ E(x,y;θ) + E_{y'~G(·|x)}[∇_θ E(x,y';θ)]`.

Gradient objektif (Eq. 44) memerlukan menjalankan seluruh litar, lalu satu sampel bantu `z(j)'` daripada `G_j` pada input yang sama (clamped). Murah, tetapi sebagai penganggar score-function, **varians tinggi**.

## IV.A Antara muka pelaksanaan

Litar diturunkan kepada DFG, setiap kernel ada kaedah `sample`. Latihan mengikut gelung hibrid Rajah 5: litar disampel, pengoptimum klasik menilai `J(θ)` dan mengemas kini θ; JAX menyediakan pembezaan automatik dan kompilasi.
