# Halaman 7: Trotter dan permulaan pembezaan

## III.B Trotterization

Penjana hasil tambah `Q = Σ_j Q_j` (Eq. 28), setiap `Q_j` pada beberapa wire, tetapi `e^{Qt}` secara amnya bukan hasil darab gate setempat.

- **Lie-Trotter** (Eq. 29): `e^{Qt} ≈ (Π_j e^{Q_j t/N})^N`. Ralat satu langkah ditentukan oleh komutator `[Q_i, Q_j]`, order `O(t²k²/N²)`; ralat global `O(t²k²/N)` (ralat bertambah paling banyak secara aditif). Peringkat pertama: gandakan N, ralat separuh.
- **Strang** (Eq. 30): urutan simetri `e^{Q_1 t/2N} ... e^{Q_k t/N} ... e^{Q_1 t/2N}`. Ralat tempatan `O(t³k³/N³)`, global `O(t³k³/N²)`, kos `2k−1` gate setiap langkah.
- **Euler** (Eq. 31): bila hanya `I + τQ_j` ada. Ralat dipecah kepada bahagian Euler `O(t²/N²)` dan bahagian splitting `O(t²k²/N²)`. Bila hanya Euler tersedia, Lie-Trotter lebih mudah dan mencukupi; bila eksponen tepat tersedia, Strang lebih baik untuk `N ≳ kt`.
- Terikat dalam mana-mana norma submultiplikatif; pemalar bergantung pada `max ||[Q_i,Q_j]||`.
- **Pengurangan k:** warnakan graf bukan-komutasi dengan χ warna; penjana warna sama komut, jadi `k → χ`. Untuk graf, pewarnaan tepi.

## III.C Pembezaan: tiga penganggar

Dilatih dengan gradient atas objektif skalar yang dianggar daripada sampel. Tiga penganggar mengikut struktur yang diandaikan: **REINFORCE** (sebarang gate licin), **parameter-shift** (gate sigmoid-mixture), **berasaskan tenaga** (gate Boltzmann).

Objektif (Eq. 32): `J(θ) = E_{Y~ρ_out(θ)}[f(Y)] = <f, G_k···G_1 ρ_in>`. Setiap `G_j` linear dalam keadaan, jadi (Eq. 33) `∂J/∂θ_j = <f, G_k···G_{j+1} (∂G_j) G_{j−1}···G_1 ρ_in>`. Dengan `(∂G)(y|x) = G(y|x) ∂ log G(y|x)` (Eq. 34):

`∂_{θ_j} J = E[ f(z(k)) ∂_{θ_j} log G_j(z(j)|z(j−1)) ]`

(halaman 8 menyambung: ini penganggar REINFORCE).
