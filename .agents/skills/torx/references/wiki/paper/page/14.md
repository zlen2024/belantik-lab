# Halaman 14: eksperimen perkakasan X0 dan kesimpulan

## V.F Rawak perkakasan untuk sampling Ising

Sasaran: cincin Ising 8 tapak, `β = 1.5`, 20,000 sampel, satu pbit X0 terkalibrasi dalam XTR-0. Cadangan ditarik sebagai Bernoulli bebas setiap tapak pada bias boleh atur cara `θ_i`. Dua algoritma:

- **Metropolis-Hastings:** bit perkakasan memaklumkan nisbah penerimaan `a = min(1, π(x')q(x) / (π(x)q(x')))`.
- **Importance sampling** berpenormalan sendiri: setiap sampel diberat `w̃(m) = π(x(m)) / q(x(m); θ)`.

`π` tepat diperoleh dengan enumerasi `2^8` konfigurasi. Keputusan (Rajah 17), TV daripada tepat:

| Kaedah | Perisian (SW) | Perkakasan (HW) |
|---|---|---|
| MH | 0.0887 | 0.1126 |
| IS | 0.0525 | 0.0622 |

Kesimpulan paper: jarak TV **konsisten** dengan asas perisian, jadi perkakasan analog memberi rawak berkualiti **kompetitif**. Perhatikan: HW sedikit lebih buruk dalam kedua-dua kes; "konsisten" bermaksud setanding dalam satu larian, tiada selang keyakinan dilaporkan pada halaman ini.

## VI. Kesimpulan

PSC = model gate untuk dinamik stokastik boleh atur cara; `torx` = rangka kerja boleh dibezakan. Antara muka menyokong simulasi vektor-kebarangkalian tepat, pelaksanaan bersampel dan rawak daripada perkakasan sambil mengekalkan satu objek PSC logik. Pustaka gate: kernel ditentukan terus, kernel terbit-penjana (PIsing), dan penghampiran Trotter bagi penjana Markov masa selanjar setempat.

Hubungan dengan `thermalizers`: dengan mengclamp pembolehubah input sebuah EBM dan mensampel outputnya, kernel stokastik direalisasi secara langsung sebagai dinamik fizikal. **Torx menentukan dan melatih kernel logik; thermalizers melaksanakannya secara asli dalam hardware.**

**Arah terbuka** (dinyatakan sendiri oleh pengarang): melaksanakan PSC secara asli pada Z1; teori umum mensintesis kernel sasaran daripada set gate tetap; mengskala demonstrasi melebihi saiz mainan.
