# Halaman 17: Appendix A dan B

## Appendix A: gate tambahan

Semua gate di bawah berbentuk **`ApplyB(p) = (1−p) I + p B`**, dan `p ∈ {0,1}` menjadikannya deterministik.

| Gate | Operasi B |
|---|---|
| `PReset(p)` | tetapkan pbit kepada 0 dengan kebarangkalian p |
| `PCNOT(p)` | balik pbit kedua jika yang pertama 1 |
| `PSWAP(p)` | tukar dua pbit |
| `PJUMP(p)` | pindahkan kebarangkalian dari `|10)` ke `|01)` |
| `PDEMUX(p)` | salin pbit pertama ke kedua dan tetapkan input kepada 0 |
| `PCopy(p)` | salin pbit pertama ke kedua |
| `PditShift(p)` | anjak pdit k-dimensi kitar `i → (i−1) mod k` |
| `PditSWAP(p)` | tukar dua pdit k-dimensi, `(1−p) I + p S` |

Matriks ditulis dalam paper (contoh `PReset(p) = [[1,p],[0,1−p]]`, `PJUMP(p)` memindahkan `|10) → |01)`). Tiada **AND** atau **darab** dalam senarai ini; itu sebab gate AND kita perlukan penalti Ising.

## Appendix B: panduan untuk pembaca dari maklumat kuantum

PSC kelihatan seperti Parametrized Quantum Circuits (PQC), tetapi beza ketara dalam pengekodan data, perakaunan larian litar dan penganggaran gradient. Gelung variasi (Rajah 5) sengaja analog stokastik gelung latihan PQC. Satu beza utama: **keadaan daftar PSC ialah taburan klasik dan bacaan ialah sampel; mengambil sampel tidak mengubah taburan**, jadi ukuran boleh dibuat pada mana-mana titik litar tanpa menjejaskan baki pengiraan. Dalam kuantum, ukuran meruntuhkan keadaan, dan gate seterusnya bertindak pada keadaan pasca-ukuran.
