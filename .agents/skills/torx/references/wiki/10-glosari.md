# 10. Glosari

| Istilah | Maksud |
|---|---|
| pbit | bit kebarangkalian, 0/1 rawak; di sini sampel Bernoulli |
| pdit | tapak d-keadaan |
| pmode | tapak selanjar dalam R^N |
| gate | kernel stokastik K(y\|x), lajur jumlah 1 |
| logit θ | `log(p/(1−p))`, parameter yang disimpan Torx |
| PSC | Parametrized Stochastic Circuit |
| DFG | Directed Factor Graph |
| factor | taburan bersyarat sebagai objek, `sample(key, inputs, params)` |
| Trotter / Strang | pemisahan hasil darab bertertib untuk menghampiri evolusi serentak |
| splitting bias | ralat daripada urutan, bukan sampel |
| CTMC | rantai Markov masa selanjar |
| Glauber | dinamik lompat satu spin |
| chromatic Gibbs | kemas kini serentak untuk tapak satu warna |
| detailed balance | syarat supaya taburan sasaran kekal tak berubah |
| PCD | persistent contrastive divergence |
| REINFORCE | anggaran gradient untuk hasil diskret, dengan baseline |
| param_map | corak notebook 08 (tatasusunan indeks numpy), bukan API Torx; mekanisme sebenar: `Site.param_key`, `TiledFactor`, `ChainFactor` |
| parameter-shift | gradient dengan menilai gate pada nilai terhad (±∞) |
| ULA / MALA | Langevin tanpa / dengan pembetulan Metropolis |
| EBM | model berasaskan tenaga |
| TSU | thermodynamic sampling unit (istilah Extropic) |
| X0 / XTR-0 | cip ujian dan platform desktop |
| Z1 | cip generasi seterusnya, graf degree-16, 269,568 p-bit |
| Thermalizers | pengkompil kernel Torx ke EBM untuk cip |
