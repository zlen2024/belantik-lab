# 10,000-word proposed training-window exposure audit

Freeze before computing. Use the same 600 training articles, tokenizer, minimum frequency 5, sorted vocabulary rule and existing document/window generators as the baseline. For the candidate 10,000-word vocabulary, generate 200,000 pair occurrences with `sample` seed 22101 and produce 200,000 three-token windows with `windows` seed 23101. This is a **prospective new sample**: sampling eligibility differs from the historical 2,000-word sample, so do not describe model comparisons as controlled only for vocabulary size. Save IDs, positions, document grouping, vocabulary hash and source hashes in a local MLflow artifact so the candidate dataset can be reused or audited. No model training or validation labels.

For the original 2,000-word data, use its existing 200,000 training windows and verify source/vocabulary/array hashes. For each word measure how often it is a center and how often it occurs anywhere in its three-token window. Report count and quantiles, including zero, one, five and ten-or-more appearances, separately for common ranks 1–2000 and newly included ranks 2001–5000 and 5001–10000. Report token-position diversity and common- vs new-word shares. Distinguish sampled occurrences from unique underlying occurrence windows, and calculate separately the repeated-presentation count under three repeats of the same sample. Softmax scores all vocabulary candidates, so a token with zero positive or context occurrences can still receive negative-class gradients; do not say its parameter receives no gradient. The audit does not prove adequate semantic learning.

Use classical CPU and record actual sampling time, source code snapshot, seed and array hashes. No SWORDS judgments, WiC labels, model performance or reserved test. This data-selection check informs a later proposal with matched model/vector training and meaningful contexts; neither scale alone nor a coverage increase meets the user's embedding or hardware objective. Independent critic reviews before a training protocol is frozen.
