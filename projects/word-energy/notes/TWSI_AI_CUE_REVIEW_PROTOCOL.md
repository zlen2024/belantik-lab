# Blind AI cue sufficiency review (exploratory)

Freeze before generating panel. Select 12 distinct target IDs from the existing connected split's **train** partition, each with a `(target, candidate A, candidate B)` group containing opposite weak-label directions in different sentence hashes and different four-cue bags. Select one group per target by deterministic seeded shuffle RNG 88121 and one row of each direction; exclude all ambiguous recovery, do not use prior model predictions. Source IDs are unknown: grouping and split are not document-disjoint. This small panel is selected on weak-label reversal, is not random over all examples, and cannot establish population performance.

Randomly swap A/B presentation independently per group (same order in both rows) using RNG 88122; shuffle the 24 rows with RNG 88123. Recover full sentence by exact original sentence hash from TWSI train only; require one unambiguous spelling for each selected hash. Use target surface word and candidate words from the model vocabulary. Full-sentence reviewer gets the original sentence with target word specified; cue reviewer receives only the unordered non-padding words actually supplied to the model, target and the same A/B options. Do not include weak labels, alternate context or prior model outputs. Each independent 6.2 Sol medium reviewer returns A, B or uncertain per row, with terse rationale. They may say uncertain if both are suitable, neither is suitable, or evidence is insufficient. An AI review is **not human validation**, independent source annotation, ground truth, nor a reliable substitute for blinded human judgments. No dev/test, training or model tuning.

After both submissions, compute row-level agreement with TWSI weak preference, uncertain fractions, full-versus-cue agreement (all rows and on joint decisive rows), and reversal groups where each reviewer independently chooses the two opposite weak-label preferences. Save blind panels, review outputs, source code, config, sample/array hashes, selection key and metrics to local MLflow only; no raw text in Git. Request independent critic after results, explicitly checking any reviewer leakage, cue-word order versus bag, candidate order bias, weak-label interpretation, source independence, and both original architecture plans. Do not claim the sample's results generalize to all TWSI or prove semantic correctness.
