# SWORDS development crossed-context support audit

Freeze before calculating counts. The target-foil objective and its target-uniform variant have exact shortcut/counterexamples. A checkerboard of candidate preferences can test stronger target/context dependence only if the inputs and judgments actually contain matched reversals. This is an exploratory audit on SWORDS development **judgments already examined**, not an unseen test or an official SWORDS metric. It does not score or train a model.

Reuse the fixed input manifest and judgment fractions in MLflow run `6bfbcadfb039410dbc206f963b50d2bf`. Its 219 input-eligible targets contain 132 with both a majority-acceptable candidate and a non-acceptable candidate after vote and vocabulary filters. Use only those 132, preserving candidate IDs, target IDs, full sorted in-vocabulary ±2 context bags, source-file proxies and `TRUE/(TRUE+FALSE)>0.5` labels. Treat candidate unordered pairs with opposite class judgments as one strict preference; ignore ties and unjudged candidates. Never use model scores for constructing matched examples.

Count (a) the number of same-target, same-candidate-pair examples with different context bags and opposite preference, (b) same-context-bag, same-candidate-pair examples with different target IDs and opposite preference, and (c) full 2×2 checkerboards over two target IDs and two context bags for one candidate pair, where the four preference signs alternate. Count unordered pairs/quadrangles once, report the number of distinct targets, contexts, candidate pairs and source-file proxies, and distinguish same-source from cross-source matches. If duplicate observations for an identical `(target, context, candidate pair)` disagree, report conflicts and omit that cell from strict matched constructions. Do not broaden context identity, labels or scope after seeing counts.

Exact-token bag matching is deliberately stringent; a low count does not show there are no natural semantic reversals. Candidate labels, contexts and target availability were filtered by a 2,000-word vocabulary, and related sentences may share a source. Random-label coverage, annotator disagreement and training-data contamination are not resolved by this audit. Store only target/candidate IDs, hashed context signatures and aggregate counts in MLflow, not raw text. Do not open the official test. An independent critic will review whether the evidence supports a useful fresh task and how both Ising and nonlinear vector controls should be compared.
