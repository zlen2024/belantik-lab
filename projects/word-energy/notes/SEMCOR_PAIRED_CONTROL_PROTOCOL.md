# SemCor paired development controls

Frozen after observing `bd4c107ad9654a1288761a207dcd7d98`: this is a post-hoc robustness check, not a blind test or an Ising/Gaussian run. Rebuild precisely the 225 inner-fit and 57 inner-validation documents with the previous frozen parsing and train-only sense choice; never read the 70 outer-reserved XML files. Verify the reconstructed 1,279-example paired accuracy counts match the earlier run before producing controls.

Record each scored occurrence's hashed document identifier, target ID, sense key, cue count, and paired correctness (not source text). Use the same train-only majority and multinomial naive Bayes models. Primary sensitivity: 2,000 bootstrap resamples of scored validation documents with replacement, sampling the 31 contributing documents as clusters; compute pooled per-example cue-minus-majority accuracy and report 2.5th/97.5th percentiles. This estimates a conditional empirical document-bootstrap interval, not a guarantee of independence or unseen-domain performance.

Negative control: shuffle complete cue bags across validation examples within each target and cue-count stratum, without moving the true labels or retraining. Use 200 independently seeded deterministic permutations from NumPy `default_rng(20261122)`; report accuracy distribution and actual unshuffled accuracy, plus fraction of rows in singleton strata whose cues cannot move. Permutation is descriptive because within-document correlation and singleton/fixed points remain; it is not a formal p-value. Report subgroup outcomes by cue count and coverage. Do not use outcomes to tune a W model or open held-out data. Record source and protocol snapshots and MLflow results.
