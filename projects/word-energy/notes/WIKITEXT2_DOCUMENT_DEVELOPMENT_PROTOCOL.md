# WikiText-2: document-separated lexical development

18 November 2026. Posthoc development follow-up after text8 results; not a confirmatory test or independent-domain replication. Source: [Salesforce WikiText-2 raw v1](https://huggingface.co/datasets/Salesforce/wikitext/tree/c937478d5e4c5aca1b3f9f12de797092d0fdfdef/wikitext-2-raw-v1), [dataset description and license](https://huggingface.co/datasets/Salesforce/wikitext/blob/c937478d5e4c5aca1b3f9f12de797092d0fdfdef/README.md), [original paper](https://arxiv.org/abs/1609.07843). Source says CC-BY-SA 3.0 and GFDL; retain attribution and links. Downloaded only official train and validation; no WikiText test file. text8 reserved test also untouched. Both corpora are Wikipedia; overlap with historical text8 not ruled out.

Parse top-level heading only when surrounded by blank rows, requiring 600 distinct train and 60 distinct validation article titles, no cross-split normalized title or normalized whole-document hash overlap. Report exact long-paragraph overlaps. Keep document ID for each sampled center. Treat each non-heading row separately; no pair crosses row/article or an intermediate OOV, including offset ±2. Lowercase ASCII alphabetic tokens via `[a-z]+`; punctuation/numbers excluded. This is project-specific tokenization, not standard WikiText perplexity.

Build vocabulary of 2,000 most frequent train tokens (count>=5; ties lexicographic), train counts and q ∝ count^.75 solely from training documents. Sample 200,000 train pairs and 10,000 validation pairs with replacement from eligible center positions, one valid context uniformly from offsets ±1/±2; 5 train noises per epoch, 20 validation noises, unconditional even when same as positive. Save all occurrence positions, document IDs, candidate noise, orders, frequency distribution and per-array hashes. One fixed context-column shuffle seed; preserve targets, context multiset, noise, initial params and orders. Report shuffle collisions and controls; one shuffle is not independent replication.

Models (each original and shuffled × seed 17/29/43): tied Ising F2 6,002 params; role Ising 12,002; directed vector 2D 8,000. Train from scratch, candidate offset 0.25 log(train count) in train and validation, shared softplus margin1 ranking loss with 5 negatives, Adam .01 clip5 batch256, fixed 3 epochs; 18 sequential runs. Canonical ordered scores; zero-coupling Ising/zero-vector must exactly reproduce frequency-only ranking on validation. Report validation micro noise AUC and expected-tie MRR@21, and document-macro AUC using 60 validation article IDs. Paired original−shuffle per seed and original−frequency-only, original Ising−vector per seed; optional fixed-seed article-bootstrap interval for paired per-document AUC differences, no independent-seed/corpus claim. Report every run, hashes/checkpoints/source, training coverage, validation OOV and full document split diagnostics. Per-seed paired initializations must match.

All analyses are developmental; no checkpoint/parameter selection using reserved test. WikiText differs from text8 in corpus, vocabulary, tokenizer and pair count: no claim that changes result from scaling alone.
