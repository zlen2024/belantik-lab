# Exact active target–candidate correlation readout

21 November 2026. `ising_active_correlations` adds an executable classical readout closer to the original Ising plan's shared-window observable. Given target word, m context word occurrences and each candidate word, create a target-centered star containing the target, the m contexts and **that candidate as an active leaf**. All occurrences use the shared word parameters but have distinct spin states, including repeated IDs. Each spoke uses the trained `g/(m+1)` coupling. Compute the target's exact 16-state posterior for that star and the exact conditional candidate distribution for each target state. The score is the joint expectation `R = (1/4) Σ_a E[s_target,a s_candidate,a]`.

Each candidate is scored in its own active window. Other candidate words are not present. Adding the candidate changes the equilibrium and changes each existing context spoke from `g/m` to `g/(m+1)`. Therefore this is not simply inspecting a second token in the previous unchanged window, and its ranking is not automatically calibrated across candidate windows. It is distinct from the host-side external-candidate affinities used in the SWORDS development probe. Since the raw correlation can be negative and has a nonzero zero-coupling baseline, it is not automatically a probability, energy or connected correlation.

`tests/test_contextual_substitution.py` compares the implementation against independently constructed full 4,096-state enumeration for target + context + candidate, and 65,536-state enumeration for a target, two repeated context occurrences and a candidate with the target word ID. It also checks the zero-coupling product of unary means and the uniform-unary closed-form `tanh(0.75/2)` for two spokes. Six tests pass using workspace system `pytest`. The original target/context/candidate probabilities and beta convention come from the existing four-spin code; no parameters or training were altered.

Independent GPT-6.1 Sol ultra review enumerated full raw energy for 135 cases, including three parameter seeds, one- and two-context windows, repeated IDs, self-word candidates as distinct occurrences, reversed contexts, duplicate candidate lists and zero coupling. Maximum error versus this implementation was 1.9984e-15, and all scores were within [-1,1]. The critic's project-venv pytest invocation was unavailable because that interpreter lacks pytest; its independent enumeration ran successfully, while the six tests above passed under system pytest. The critic also kernel-checked the finite expectation factorization `Σ_i Σ_j p_i q_j a_i b_j = (Σ_i p_i a_i)(Σ_j q_j b_j)` using pinned Lean 4.36.0 / Mathlib `fc4f59e...`, `lake env lean --stdin`, with only `propext`, `Classical.choice`, `Quot.sound` axioms and no `sorryAx`. Applying the identity here additionally requires independence of the zero-coupling joint law.

For m context occurrences, this target–candidate star has `4(m+2)` spins, `10m+16` potential edges and maximum degree `m+4`. This is a classical exact reference and software entry point, with no new benchmark result. To support a thermodynamic interpretation, the *same active-window* observable and graph require THRML sampled-versus-exact parity, including uncertainty and rare events; prior four-spin sampler gates failed and remain failed. Larger m changes the graph and spokes and must be accounted for. Physical chip adjacency, loading, calibration, energy and speed remain unmeasured. A meaningful substitution task additionally requires frozen candidate generation, controls, coverage and fresh evaluation, and should not reuse a development score as confirmation.
