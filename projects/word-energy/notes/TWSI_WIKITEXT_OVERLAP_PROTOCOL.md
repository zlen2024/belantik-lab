# TWSI/WikiText train exact-overlap audit

Before running: read only `twsi_train.tsv` in the pinned ALaSca archive and existing `data/wikitext2/train.parquet`. Ignore all judgment, dev and test entries. Lowercase and tokenize ASCII letter/digit runs (`[a-z0-9]+`) consistently; identify exact TWSI sentence token sequences as contiguous subsequences within one WikiText training parquet row. For sentences with at least five tokens, index the first five tokens as an accelerator, then verify the entire sequence, not only the hash/prefix. Report TWSI occurrence and unique normalized sentence counts, overlaps and WikiText row counts. Compare to package/train file SHA-256 and log the source/record. This detects only exact matches under this normalization and paragraph boundary, not near duplicates, related pages, pretraining on other data or overlap with held-out data. It does not establish document independence. Critique after results.
