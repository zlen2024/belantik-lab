21 November 2026. GPT-6.1 Sol ultra independently checked the frozen protocol, code, source hashes, checkpoint hash verification and MLflow run `88afd4e4710a4da3b36080581905ff07`. All 219 × 3 shared predictions reproduced exactly, and independent pair counts reproduced saved shared and uniform per-target AUCs. Global Python 3.13 `python -m pytest tests/test_contextual_substitution.py -q` gave 10 passed; the project virtual environment has no pytest. No sign or normalization defect was found in the stated exact scorer.

**Kritik eksperimen:** shared versus old candidate-specific changes both the participation of other alternatives and the spoke scale. Candidate counts are 2–49; `m/(m+K)` ranges 0.0465–0.6667. The frozen checkpoints were trained with two leaves. Uniform dummy contexts remove context identity while preserving the other candidates and scale; that control is not chance. Shared candidate pools also add collective information beyond observed sentence tokens. Development labels were repeatedly used and text overlap with training has not been audited here. Sixteen source proxies and three fixed seeds make the bootstrap descriptive, not a population-wide guarantee. The primary result and dominant-source sensitivity are in [the results](SWORDS_SHARED_STAR_PROBE_RESULTS.md).

**Kritik hipotesis:** simply adding all alternatives to one shared star did not demonstrate better performance for these fixed models. This does not test whether a model trained for an appropriate shared landscape can learn useful contextual semantics. Neither original plan requires all proposed substitutes to be added as active tokens. The Gaussian baseline and hardware mapping were not evaluated.

**Lean:** `lake build WordEnergy.Boltzmann` and `lake env lean SharedStarCriticAudit.lean` both exited 0 in the pinned theory directory using Lean 4.36.0 and Mathlib `fc4f59e577feb1a4956671bc04ac18aaaf8cd842`. The two lemmas show finite product-expectation factorization and uniform ±1 spin message neutrality. Both use `propext`, `Classical.choice`, `Quot.sound`, without `sorryAx`; see [Lean source](../theory/SharedStarCriticAudit.lean). They do not verify float implementation, learned semantics, generalization or chip execution.

**One bounded next action:** for each scored candidate, replace the other candidate leaves with uniform dummies while retaining all `m+K` leaves and normalization `g/(m+K)`. Compare shared versus this matched control to examine effects of other candidate identities, and matched control versus the old candidate-specific score to examine normalization/topology effects. This is a development diagnostic, not independent validation or a replacement architecture; avoid open-ended readout search. The degree issue also motivates a genuinely sparse active graph and a task-aligned training objective before scale. Keep the official test closed and Gaussian as a separate classical comparator.
