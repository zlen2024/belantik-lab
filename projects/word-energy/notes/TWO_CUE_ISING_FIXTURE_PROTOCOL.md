# Two-cue Ising representability fixture

This pre-training fixture checks the actual four-spin Ising star and center posterior for a fixed, hand-constructed two-cue parity task. It does not measure learned language, trainability, generalization, Gaussian capability, or hardware. Define one target token and four cue tokens A0/A1/B0/B1. Target unary is uniform. A cues have opposite fields only on spin 0; B cues have opposite fields only on spin 1. All internal couplings are zero and four inter-token couplings equal 0.8, with two spokes scaled by 1/2, as in `wikitext_four_spin_wic.posterior`. Define sense 1 by target states where `s0*s1 < 0`. In the four input combinations (A0,B0), (A0,B1), (A1,B0), (A1,B1), the desired labels are 0,1,1,0.

Calculate the normalized target posterior by the production posterior routine and independently by explicit enumeration of all 4,096 joint states. Check every probability and region mass to absolute tolerance 1e-12, cue swapping, flip of each cue, and exact 0.5 region probability when interaction is zero. Verify strict separation by 0.5, report the smallest margin. Enumerate a bounded set of additive linear thresholds to obtain a 3/4 witness, and establish the XOR accuracy ceiling analytically from the four score inequalities, and demonstrate a nonlinear vector product readout with 4/4. A score tie must not count as a correct strict classification. Log fixed parameters, state conventions, code snapshot, outputs and limitations in MLflow, using execution tier classical. Four possible labels and hand-selected states are an oracle capacity check. The comparator operates on cue signs and is not a trained language embedding.

After the result obtain an independent critic review of equations, actual code and both original research plans. Do not use this small fixture as evidence that semantic meanings or a physical chip are trained. Gaussian representability and held-out benchmark design remain separate open checks.
