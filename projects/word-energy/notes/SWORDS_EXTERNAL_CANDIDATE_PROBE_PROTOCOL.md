# SWORDS development external-candidate probe

Frozen before reading judgments or scoring models. The target, context and supplied candidate list come from the SWORDS v1.1 development file pinned in `SWORDS_COVERAGE_AUDIT_PROTOCOL.md`. This is an exploratory candidate-ranking task on a restricted input subset, not the official SWORDS overall score, an unseen test, or evidence of embedding replacement. Candidate judgments were loaded into memory during the preceding coverage audit but were not inspected or used.

## Readouts and checkpoints

Use the three fixed four-spin full-softmax Ising checkpoints `34ad840584164e5dac2059ca6ef5267b`, `6fd4829031424eba917b99c5fd1ab9ca`, `2ee7dde861fa4e82b960c0767e4bef6b`, and matched tied vector checkpoints `ba3d1cfad0214f36ac30c9cf66c43b23`, `282b6343c23b443ea852d7ef4076aafa`, `f28f6fbb35c848d8b2947c448cb61f2d`. All used WikiText data and log-count full-softmax. Verify training data and checkpoint hashes. Scorers are fixed; do not fit or choose hyperparameters using SWORDS judgments.

For target w and context C of m words, Ising's reference is the exact production star posterior `p(s|w,C)` with normalized spokes `g/m` and unary `q_w`. Each candidate c is **external**, represented by its normalized unary `q_c`; the primary score is `log Σ_s sqrt(p(s|w,C) q_c(s))`. Higher means more similar state distributions. This is a host-side distribution affinity and not the original shared-window correlation R. The variable m may be 1–4, while training used 2. For the matched vector, score candidate by cosine of `v_c` and `v_w+mean(v_C)` using the same tie-safe cosine helper as WiC. All candidates receive identical inputs.

Predeclared controls: Ising target-only unary affinity, Ising context-only affinity with a uniform center unary, vector target-only cosine, vector context-only cosine, vector target-plus-context dot product, and log-count frequency-only rank. A zero-norm vector in the frozen eligible inputs causes an explicit run failure before labels are analyzed; it is not silently dropped. This follows the previously used WiC cosine helper, while the original Gaussian toy plan describes zero-norm cosine as zero, so do not claim those policies coincide. The secondary Ising kernel score is `log Σ_s,t p(s|w,C) q_c(t) exp[(g/2)·(s*t)]`; it reflects one trained pair coupling but remains an external-candidate host score, not a measured same-window R. Do not select a winner among readouts based on observed development labels. Gaussian joint has no natural-text checkpoint or validated matching implementation and is not included; make no cross-plan model superiority claim. CPU runtimes are illustrative and do not establish thermodynamic hardware performance.

## Eligibility and labels

Construct label-blind eligible inputs as in the earlier coverage audit, except exclude both original surface and the provided CoInCo target lemma from candidate strings. Require target as exact single ASCII-token span in vocabulary and at least one in-vocabulary context token within ±2; candidates must be unique, lowercase single ASCII tokens in vocabulary. Resolve each eligible target to exactly one `coinco_ids` source-file prefix; if metadata has zero/multiple files report and exclude rather than guess. Freeze the eligible target/candidate ID manifest and its hash before using judgments. Report missing source, target, context and candidate coverage, including 370 total and train vocabulary coverage.

After input eligibility freezes, aggregate identical candidate strings' judgments; remove `UNSURE`. Treat candidate as acceptable if `TRUE/(TRUE+FALSE)>0.5`, following the official acceptable threshold. Include candidates with at least one non-UNSURE vote. Within each target with at least one acceptable and one non-acceptable candidate, calculate all cross-class pairwise ranking comparisons, awarding ties 0.5. Average comparisons within each target, then average target AUC. Report count of targets excluded because labels offer no contrast, candidate counts and votes. Do not call this the official SWORDS metric: supplied candidates, vocab filtering and target preprocessing differ from the official whole-benchmark generation task. No target examples are selected using model scores.

## Comparisons and uncertainty

For Ising affinity minus vector target-context, and Ising affinity minus Ising target-only, calculate per-target paired differences, average over the fixed three seeds, then use 1,000 bootstrap resamples of the source-file proxy clusters with RNG seed 23140. Weight targets equally in each cluster resample. Report CI, per-seed differences, fraction of valid resamples and the entire result with and without the pre-identified largest source `Nathans_Bylichka.txt`; do not choose which to emphasize posthoc. Report all controls and the secondary kernel using the same candidate IDs and label subsets. Document per-seed score-tie rate and candidates with nonfinite scores as failures rather than dropping them. For interpretation, also report per-target predicted score spread, candidate unary entropy, and target-only versus context-sensitive rank changes; these are descriptive and do not establish why an effect occurs.
