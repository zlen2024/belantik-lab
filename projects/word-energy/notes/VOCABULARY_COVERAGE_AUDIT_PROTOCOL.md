# Vocabulary expansion coverage audit

Freeze before computing. The current 2,000-word model covers only a fraction of SWORDS development inputs. Estimate what expanding a **train-only** WikiText-2 vocabulary can and cannot cover, before training a larger model. Use the exact same 600 WikiText train articles, tokenizer, minimum count of 5, descending frequency and alphabetical tie ordering used in the existing data build. Consider requested top 2,000, 5,000, 10,000, 20,000, and all tokens meeting count ≥5. The last option may have fewer than a requested size; report actual sizes. Verify the first 2,000 entries exactly match the existing frozen model vocabulary.

For each vocabulary, audit token coverage on train and on WikiText validation inputs without accessing any test split, and SWORDS v1.1 development input/candidate availability using the `SWORDS_COVERAGE_AUDIT_PROTOCOL.md` target-span, ±2 context and distinct in-vocabulary single-token candidate rules, excluding both target surface and supplied target lemma. Do not inspect candidate judgment labels or evaluate models. Report total target, context eligibility, at least 1/2/5/10 candidate IDs, candidate identity coverage including OOV and multiword exclusions, input frequencies and parameter/score scaling estimates. Use the same target and candidate denominator for all sizes. Count vocabulary commonality against original checkpoint and retain the target/cooccurrence tokenizer caveats. Keep SWORDS test untouched.

This is a posthoc development feasibility audit. SWORDS development judgments were previously evaluated for the existing model, so vocabulary selection informed by this audit is not independent test evidence. A larger vocabulary does not produce trained parameters for new words, address unseen-word inference or demonstrate semantic quality. Matched vector, natural-context accuracy, train budget, cost, rare-word reliability and THRML mapping need separate assessment. Save counts, hashes, exact code/protocol and limitations to MLflow. Obtain independent critic after results before deciding whether training or another intervention serves the two plans.
