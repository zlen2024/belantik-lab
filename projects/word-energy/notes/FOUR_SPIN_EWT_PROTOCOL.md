# Replikasi retrieval luar domain sebelum scaling

Bekukan sebelum mengambil skor. Sumber ialah development UD English EWT release r2.15, hanya komen newdoc id dan text. Dataset ini mengandungi beberapa genre teks web bahasa Inggeris. Guna seluruh dokumen yang layak; singkirkan ID bertindih, dokumen sama dan ayat sekurang-kurangnya 80 aksara yang sepadan selepas normalisasi dengan WikiText train/validation. Simpan hash fail dan manifest. Vocabulary, semua parameter, prior, pekali log(noise_q)=1 dan tiga checkpoint dibekukan daripada WikiText. Tokenizer dan jarak konteks sama, tanpa merentasi sempadan ayat. Sampel 10,000 window (RNG 24101 dan 24102, melalui pool 40,000 pasangan). Lapor bilangan dokumen sebenar yang dinilai, coverage token dan had generalisasi.

Primary: MRR purata setiap dokumen, joint berbanding prior dan bacaan additive pada parameter sama. Kedua-dua perbezaan mesti positif pada semua tiga seed dan had bawah 95% selang paired document bootstrap (1000 draws, RNG 23140) melebihi sifar bagi kedua-duanya. Lapor vector10, MRR window, recall@10 sebagai tambahan. Split rasmi WikiText test kekal reserved. Kejayaan membenarkan pilot learning curve terkawal. Eksperimen ini mengukur retrieval perkataan di bawah vocabulary terhad.
