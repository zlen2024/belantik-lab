# Spin8 evaluation loading repair

22 November 2026. All six frozen fits completed, but the first evaluation invocation failed before producing any score or starting an evaluation MLflow run. Reloaded `.npz` parameters were NumPy arrays captured inside a JAX-jitted scorer, causing `TracerArrayConversionError` on token indexing. Repair converts all loaded arrays to JAX arrays before tracing and adds `test_jitted_reload_from_numpy_checkpoint`; no model weights, split, outcome, metric or comparison was changed. The failed command was `python scripts/evaluate_spin8_prospective.py 3387fc4fb99646f1b7aacd518f39bf10` as launched by `run_spin8_prospective.py`. Original source commit `16d0dfa` and this repair are both retained. Final holdout scores had not been emitted before repair. Evaluation will run once on the existing six checkpoints, with no retraining.
