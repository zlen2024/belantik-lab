# Six vs eight spins: prospectively separated article pilot

Freeze before preparing data or seeing results, 22 November 2026. Hypothesis: increasing Ising per-token capacity from 6 to 8 spins with a learnable relative diagonal W improves lexical discrimination. This is one natural-text pilot, not a test of sense/landscape advantage. Official WikiText validation and test remain closed in this pilot.

From the 600 source WikiText training articles, sort unique normalized titles by `SHA256('spin8-holdout-v1:'+title)` and reserve exactly 60; remaining 540 are fit. Preserve source order within each partition. Fail on duplicate title, whole normalized article hash or exact normalized paragraph ≥80 characters across partitions. Near-duplicate or shared sources are still possible. Build vocabulary (2,000 most common words with count≥5), counts, .25 log-count prior and count^.75 noise distribution **from 540 fit articles only**; report validation coverage and frequency. Use existing tokenization/sample routine. Seed RNG 89101 samples 10,000 fit pairs; RNG 89102 samples 2,000 reserved pairs; sample context within ±2 without crossing paragraphs or excluded words. Per epoch noise uses RNG 89110+epoch, heldout noise 89103, and orders 89120+epoch. Noise corrupts the center and rejects exact center if the existing `noise_rows` helper does so; record observed collisions rather than assume. One observed context token, five noise each. Fit and heldout are sampled with replacement; report duplicate position pairs, document counts and hash all arrays.

Six independent runs: Ising d=6 and d=8, each seed 17/29/43; identical fit pairs, noise, ordering, Adam .01, batch128, 3 epochs (237 updates), clip5, same positive/negative margin objective, fixed last checkpoint. Word unary uses all pairwise internal couplings plus fields and the same `g_i=(.8+.3*(tanh(u_i)-mean tanh(u)))/d`; total W=.8 and relative weights learn. Scores are normalized-unary pair log partitions plus .25 log fit-only count prior. Evaluate all six final checkpoints on reserved documents **only after every training run finishes**, never evaluate initial/intermediate holdout or select checkpoint by it. 6 spins = 64 unary states/21 parameters per word; 8 = 256 states/36 parameters; 2-word graphs have 12/16 spins, 36/64 edges, max degree 6/8. Efficient tensor-product kernel is mathematically equivalent to the dense diagonal Ising kernel; test score and all gradients against dense for both d before training, plus finite/ID/bounds and zero coupling. Run CPU only, 4 threads, cap 2 GiB, deadline 15 min.

Primary: heldout document-macro AUC for 8−6 and each model minus prior-only; report all three paired seed differences and a 95% paired article-bootstrap (2,000 draws, RNG 89130) on seed-mean per-document values. A decision to advance requires all three seed differences for both comparisons positive and lower bootstrap interval >0; this is a strict exploratory gate chosen before results, not a statistical guarantee. Also report pooled pair AUC, prior-only, training loss, score variance, W, time, memory and coverage. Pair ranking uses observed vs sampled noise; random noise may be a valid neighbor and collisions count as ties. Parameter and compute differ with width; 6→8 is a model-family capacity comparison, not isolated spin-only causal inference.

No raw sentences or original data in Git; log dataset arrays, fit/heldout doc ID hashes, config, checkpoints, predictions, metrics and code in MLflow. Same-domain WikiText, historical exposure to the source train corpus, vocabulary coverage, weighting/source leakage and near-duplicates limit independence. Distinguish current-run document isolation from an untouched benchmark. No Gaussian, THRML sampler or chip claim. Independent 6.2 Sol medium critic after results must check preprocessing and split, score/gradient, W, metrics, leakage and whether this answers user goal and two plans. Do not use the reserve repeatedly for tuning.
