# Pilot 200k kepada 400k sampel pada bajet yang sama

Guna WikiText train, kamus asal, tiga seed dan kedua-dua model joint4/vector10. Jadual asal A/A/A menggunakan 200k window yang sama tiga kali. Jadual pilot A/B/A menggantikan hanya pass kedua dengan 200k sampel baru daripada corpus dan generator sama (RNG 25101 untuk pasangan, 25102 untuk window). B mungkin mengandungi kedudukan sama. Rekod bilangan kedudukan unik. Jumlah latihan kedua-duanya 600k presentasi. Semua noise unconditional, orders, initialization, Adam, batch, dan prior sama. Reproduce hash checkpoint pass pertama sebagai kawalan. Ulang pass ketiga asal. Ukur MRR seluruh 2,000 calon dengan pembetulan log q tetap pada WikiText validation dan EWT dev. Kedua-dua panel kini development. Utama ialah beza MRR purata artikel joint4 pilot lawan joint4 asal pada WikiText, 1,000 paired article bootstrap. Jika semua seed positif dan interval bawah positif, lapor manfaat sampel tambahan pada setup ini. Lapor vector dan EWT berasingan. Pilot ini menambah kepelbagaian tetingkap, bukan bilangan artikel, spin atau saiz kamus.
